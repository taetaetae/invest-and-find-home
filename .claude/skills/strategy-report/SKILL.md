# Strategy Report

재무 시뮬레이션의 9가지 시나리오(목표 자산 3가지 × 월 수익률 3가지)별 최대 가능 금액 내에서, 가장 공격적인(비싼) 월세 TOP 10 매물을 추천하는 HTML 리포트를 생성하는 스킬.

## 리포트 원칙

### 1. 구성: 9가지 시나리오별 월세 TOP 10

각 시나리오별로 매물을 가격 내림차순으로 정렬하여, 목표 자산에 도달 가능한 범위 내에서 가장 비싼 매물 10개를 선정한다.

### 2. 각 매물에 포함할 정보

```
- 단지명, 면적(평수), 층수, 건축년도
- 월세: 보증금 / 월세
- 보증금 구성: 자기자본 + 대출 내역
- 대출 월이자 (회사 지원 반영 후 실질 부담액)
- 월 총 주거비 (대출이자 + 월세)
- 남은 투자금
- 목표일 예상 자산 (복리 계산)
- 목표 달성률 (%)
```

cashflow 계산 공식:
```
대출_금액 = min(보증금, 대출한도)
자기자본_투입 = 보증금 - 대출_금액
남은_투자금 = 총자산 - 자기자본_투입
대출_월이자 = 대출_금액 × max(0, 대출금리 - 회사지원금리) / 100 / 12
월_총_주거비 = 대출_월이자 + 월세
목표일_예상자산 = 남은_투자금 × (1 + 월수익률/100)^남은개월수 (매월 주거비 차감 복리)
달성률 = 목표일_예상자산 / 목표자산 × 100
```

### 3. 매물 정렬 규칙

- 월세: 보증금 내림차순 (동일 보증금이면 월세 오름차순)
- 목표 달성률이 100% 미만이면 경고 표시

## HTML 리포트 구조

### 레이아웃

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>주거 전략 리포트</title>
  <style>/* 인라인 CSS — 외부 CDN 의존 없음 */</style>
</head>
<body>
  <!-- 1. 헤더: 사용자 조건 요약 (자산, 목표 3가지, 수익률 3가지, 지역) -->
  <!-- 2. 시나리오 매트릭스: 9가지 시나리오 요약 (목표×수익률 조합별 상한선) -->
  <!-- 3. 시나리오별 월세 추천 TOP 10: 매물 테이블 (단지명, 면적, 보증금/월세, 투자가능금, 예상자산, 달성률) -->
  <!-- 4. 대출 조건 요약 -->
  <!-- 5. 면책 조항 -->
</body>
</html>
```

### 디자인 원칙

- 외부 CDN/라이브러리 없이 순수 HTML+CSS로 구현한다. 이유: 오프라인에서도 열 수 있어야 하고, 외부 의존성은 깨질 수 있다.
- 반응형 디자인 — 모바일에서도 읽기 좋게
- 색상 체계:
  - 안전(낮음 리스크): `#4CAF50` (녹색)
  - 중간 리스크: `#FF9800` (주황)
  - 높음 리스크: `#F44336` (빨강)
- 자산 변화는 CSS 기반 바 차트로 시각화 (JavaScript 없이)
- 금액 표시: 억/만원 단위로 읽기 쉽게 (예: 3억 5,000만원)

|---|--------|------|---|-----------|-----------|---------------|--------|

## 출력 파일

HTML을 분할 생성한 후 Bash cat으로 조합한다. 각 파일은 3KB 이하로 제한한다.

```
{RUN_DIR}/
├── 03_report/
│   ├── header.html              # DOCTYPE + CSS + 사용자 조건 요약 (~3KB)
│   ├── scenario_{id}.html       # 시나리오별 섹션 (각 ~2-3KB)
│   └── footer.html              # 면책 조항 (~500B)
└── housing_report.html          # 최종 조합 (Bash cat)
```

03_strategies.json은 생성하지 않는다 (HTML에 직접 포함).
